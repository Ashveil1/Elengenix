# F2: AI Agents for Pentesting/Security Using External Reasoning Architectures

**Date:** 2026-07-17
**Focus:** Real pentesting AI agents that use external planners, symbolic verifiers, or structured reasoning -- and how they differ from pure LLM internal reasoning.

---

## TL;DR

The pentesting AI agent field (2023-2026) shows a clear evolutionary arc: early agents relied entirely on LLM internal chain-of-thought, but the current state-of-the-art systems increasingly externalize planning, state management, and verification into dedicated architectural components. The strongest empirical evidence comes from CHECKMATE (classical planner), ZERO-APT (architectural enforcement), Pen-Strategist (fine-tuned reasoning + CNN classifier), and G-CTR (neurosymbolic game-theoretic reasoning). These systems consistently outperform pure LLM reasoning on both success rate and cost/stability metrics.

---

## Finding 1: CHECKMATE -- Classical Planning as an External "Brain"

**Paper:** Wang et al., "Automated Penetration Testing with LLM Agents and Classical Planning" (arXiv:2512.11143, Dec 2025)

**Architecture:** The Planner-Executor-Perceptor (PEP) paradigm. CHECKMATE integrates a classical AI planner (e.g., PDDL-based) as the external strategic brain, while LLMs handle natural language interpretation and command generation as the executor.

**Key claim:** LLM agents "struggle with maintaining coherent long-horizon plans, performing complex reasoning, and effectively utilizing specialized tools." CHECKMATE addresses this by providing "an external, structured 'brain' that mitigates the inherent weaknesses of LLM agents."

**Performance evidence:**
- CHECKMATE outperforms Claude Code (the prior SOTA) by **over 20%** in benchmark success rates
- Cuts both time and monetary costs by **more than 50%**
- Delivers substantially greater stability than pure LLM approaches

**Why it matters:** This is the strongest direct A/B comparison of external classical planning vs. pure LLM reasoning in pentesting. The classical planner provides determinism and long-horizon coherence that LLMs lack.

**Source:** https://arxiv.org/abs/2512.11143

---

## Finding 2: ZERO-APT -- Architectural Enforcement Moves Consistency Out of LLM

**Paper:** Zheng & Zhu, "ZERO-APT: A Closed-Loop Adversarial Framework for LLM-Driven Automated Penetration Testing under Intelligent Defense" (arXiv:2606.05567, Jun 2026)

**Architecture:** Three architectural mechanisms explicitly move causal consistency "from unstable LLM reasoning into enforced system architecture":
1. **Separation of planning from execution** -- different agents handle strategy vs. command generation
2. **Multi-dimensional ReAct feedback** -- structured feedback loops, not just raw command output
3. **Hard-constraint-filtered action library** -- a curated action space that prevents invalid actions

Plus a dedicated Judge agent that maintains global state and emits structured CTI reports.

**Performance evidence:**
- 79% attack success rate (vs. Aurora 22%, PentestGPT 39%)
- Causal Consistency Score of 0.860 (vs. Claude Code 0.520)
- Full end-to-end decision auditability

**Why it matters:** Demonstrates that when you remove the burden of consistency from the LLM and enforce it architecturally, both performance and auditability improve dramatically. The paper explicitly states that relying on LLM reasoning for consistency is "unstable."

**Source:** https://arxiv.org/abs/2606.05567

## Finding 3: G-CTR -- Neurosymbolic Architecture with Game-Theoretic Symbolic Reasoning

**Paper:** Mayoral-Vilches et al., "Towards Cybersecurity Superintelligence" (arXiv:2601.14614, Jan 2026)

**Architecture:** Generative Cut-the-Rope (G-CTR) is a neurosymbolic architecture that embeds game-theoretic reasoning into LLM-based agents. Symbolic equilibrium computation augments neural inference.

**Key claim:** "Symbolic equilibrium computation augments neural inference, doubling success rates while reducing behavioral variance 5.2x and achieving 2:1 advantage over non-strategic AI in Attack & Defense scenarios."

**Performance evidence:**
- Doubles success rates compared to pure neural approaches
- Reduces behavioral variance by **5.2x**
- Achieves **2:1 advantage** over non-strategic AI in adversarial scenarios

**Why it matters:** This is the clearest example of a neurosymbolic approach in cybersecurity -- the symbolic layer (game-theoretic equilibrium computation) provides what the neural layer cannot: provable strategic reasoning under adversarial conditions. The 5.2x variance reduction is particularly significant for reliability.

**Source:** https://arxiv.org/abs/2601.14614

## Finding 4: Pen-Strategist -- Fine-tuned Reasoning Model + CNN Classifier for Action Selection

**Paper:** Ginige et al., "Pen-Strategist: A Reasoning Framework for Penetration Testing Strategy Formation and Analysis" (arXiv:2605.04499, May 2026)

**Architecture:** Two external components beyond the base LLM:
1. A **fine-tuned Qwen-3-14B reasoning model** trained via reinforcement learning on a domain-specific pentesting reasoning dataset with logical explanations
2. A **semantic-based CNN classifier** that converts strategies into actionable steps (replacing LLM-based action selection)

**Performance evidence:**
- 87% improvement in strategy derivation over baseline
- 47.5% improvement in subtask completion when integrated into PentestGPT (outperforming GPT-5)
- CNN classifier outperforms commercial LLMs by **28%** for step prediction
- Demonstrates superior performance vs. Claude-4.6-Sonnet in user study

**Why it matters:** Shows that even within the LLM paradigm, externalizing strategy generation (via a specialized fine-tuned model) and action selection (via a symbolic CNN classifier) dramatically outperforms using a single general-purpose LLM for everything.

**Source:** https://arxiv.org/abs/2605.04499

## Finding 5: Cochise -- Separated Planner-Executor with External State

**Paper:** Happe & Cito, "Cochise: A Reference Harness for Autonomous Penetration Testing" (arXiv:2605.11671, May 2026)

**Architecture:** A minimal (597 LOC) reference harness implementing a "separated Planner-Executor architecture in which long-term state is maintained outside the LLM context." The executor is ReAct-style but critically, state lives externally.

**Key insight:** The paper is explicitly designed to isolate the contribution of architectural choices. It demonstrates that even a simple separation of planner and executor with external state management is sufficient to achieve functional autonomous pentesting.

**Why it matters:** As a controlled experimental harness, Cochise helps answer "what is gained over a simple agent scaffold?" -- confirming that external state management is a foundational architectural requirement, not just an optimization.

**Source:** https://arxiv.org/abs/2605.11671

## Finding 6: D-CIPHER -- Multi-Agent Planner-Executor with Dynamic Feedback

**Paper:** Udeshi et al., "D-CIPHER: Dynamic Collaborative Intelligent Multi-Agent System with Planner and Heterogeneous Executors for Offensive Security" (arXiv:2502.10931, Feb 2025)

**Architecture:** Separates the Planner agent (overall problem-solving strategy) from multiple heterogeneous Executor agents (individual task execution), with dynamic feedback loops. An Auto-prompter agent generates optimized initial prompts.

**Key insight:** "Early attempts to apply LLMs for solving CTF challenges used single-agent systems, where feedback was restricted to a single reasoning-action loop. This approach was inadequate for complex CTF tasks."

**Performance evidence:**
- State-of-the-art on three benchmarks: 22.0% NYU CTF Bench, 22.5% Cybench, 44.0% HackTheBox
- Solves 65% more MITRE ATT&CK techniques than previous work
- 2.5% to 8.5% improvement over prior work across benchmarks

**Why it matters:** Demonstrates that decomposing the problem across specialized agents (planner + heterogeneous executors) with external coordination outperforms monolithic single-agent LLM reasoning.

**Source:** https://arxiv.org/abs/2502.10931

## Finding 7: PentestGPT -- The Baseline: Externalizing Domain Knowledge into Prompt Architecture

**Paper:** Deng et al., "PentestGPT: An LLM-empowered Automatic Penetration Testing Tool" (arXiv:2308.06782, Aug 2023)

**Architecture:** Three self-interacting modules, each addressing individual sub-tasks, to mitigate context loss. Security expertise is "externalized" into natural language guidance through structured prompts.

**Performance evidence:**
- 228.6% improvement in task completion over GPT-3.5
- 4,700+ GitHub stars

**Why it matters:** PentestGPT represents the first generation of externalization -- not external computation, but external knowledge structuring. It shows the limits of this approach: LLMs still "encounter difficulties maintaining an integrated understanding of the overall testing scenario." This limitation motivated all subsequent work on true external planning.

**Source:** https://arxiv.org/abs/2308.06782

## Finding 8: HackSynth -- Dual-Module Architecture (Planner + Summarizer)

**Paper:** Muzsai et al., "HackSynth: LLM Agent and Evaluation Framework for Autonomous Penetration Testing" (arXiv:2412.01778, Dec 2024)

**Architecture:** Dual-module architecture with a Planner module and a Summarizer module. The Planner generates commands while the Summarizer processes feedback iteratively.

**Key insight:** Even within a single LLM, separating the planning and summarization functions (rather than doing everything in one prompt) improves performance. The paper establishes important benchmarks across 200 CTF challenges.

**Why it matters:** Represents the transition point -- showing that even lightweight structural separation within LLM-based systems yields benefits, which motivated the more radical externalization in later work.

**Source:** https://arxiv.org/abs/2412.01778

---

## Finding 9: APT-Agent -- Hybrid Rectification Module for Hallucination Recovery

**Paper:** Li et al., "APT-Agent: Automated Penetration Testing using Large Language Models" (arXiv:2605.24949, May 2026)

**Architecture:** Introduces a **hybrid rectification module** to recover hallucinated commands and a **command-specific memory architecture** to preserve operational context. These are external modules that detect and correct LLM errors.

**Performance evidence:**
- 84.29% end-to-end exploitation success rate
- vs. 48.57% (Script Kiddie baseline) and 18.57% (PentestGPT) under matched conditions
- More than 4x improvement over PentestGPT

**Why it matters:** Demonstrates that external error detection and correction modules can dramatically improve reliability. The hallucination rectification module acts as a symbolic verifier -- checking LLM outputs against known command patterns.

**Source:** https://arxiv.org/abs/2605.24949

## Finding 10: PentestEval Benchmark -- Evidence That Structured Reasoning is Necessary

**Paper:** Yang et al., "PentestEval: Benchmarking LLM-based Penetration Testing with Modular and Stage-Level Design" (arXiv:2512.14233, Dec 2025)

**Key finding:** "End-to-end pipelines reach only 31% success rate, and existing LLM-powered systems such as PentestGPT, PentestAgent, and VulnBot exhibit similar limitations, with autonomous agents failing almost entirely."

**Critical conclusion:** "Autonomous penetration testing demands stronger structured reasoning, where modularization enhances each individual stage and improves overall performance."

**Why it matters:** This independent benchmark study provides evidence that the field's current ceiling is fundamentally limited by reliance on LLM internal reasoning, and that modular/structured approaches are necessary for further progress.

**Source:** https://arxiv.org/abs/2512.14233

---

## Finding 11: Scaling vs. Architecture -- The Baselines Before Architecture Study

**Paper:** Dhakal et al., "Baselines Before Architecture: Evaluating Coding Agents for Autonomous Penetration Testing" (arXiv:2607.13085, Jul 2026)

**Key finding:** "Plain coding agents already solve a large share of the benchmark; repeated plain-agent runs can match or exceed some published architecture scores in union coverage, and newer models substantially improve the same scaffold."

**Nuanced conclusion:** "Specialised harnesses can add measurable benchmark lift and may improve cost efficiency, but plain coding agents already solve a large share of the benchmark."

**Why it matters:** This is a critical reality check. It shows that raw model capability is catching up with architectural innovations, BUT it also shows that architectural innovations consistently improve cost efficiency and reliability. The paper argues for model-matched baselines before attributing gains to architecture.

**Source:** https://arxiv.org/abs/2607.13085

---

## Finding 12: xOffense -- Domain-Adapted LLMs within Structured Multi-Agent Orchestration

**Paper:** Luong et al., "xOffense: An Autonomous Multi-Agent Framework for Penetration Testing with Domain-Adapted Large Language Models" (arXiv:2509.13021, Sep 2025)

**Architecture:** Fine-tuned Qwen3-32B with specialized agents for recon, vulnerability scanning, and exploitation, coordinated by an orchestration layer. Chain-of-Thought data used for fine-tuning.

**Performance evidence:**
- 79.17% sub-task completion rate
- Outperforms VulnBot and PentestGPT

**Why it matters:** Demonstrates that domain adaptation (fine-tuning on security-specific CoT data) combined with structured multi-agent orchestration achieves superior results. The orchestration layer acts as an external coordinator that pure LLM reasoning cannot provide.

**Source:** https://arxiv.org/abs/2509.13021

## Synthesis: How External Reasoning Differs from Pure LLM Reasoning

| Dimension | Pure LLM (Internal CoT) | External Reasoning Architecture |
|---|---|---|
| **Planning horizon** | Degrades over long sequences; context window limits | Classical planners maintain global state indefinitely |
| **Consistency** | "Unstable" (ZERO-APT paper); Causal Consistency Score 0.520 for Claude Code | Architecturally enforced; 0.860 for ZERO-APT |
| **State management** | Lost between turns; summarized (lossy) | External state stores preserve full context |
| **Error correction** | Relies on LLM self-correction (unreliable) | Dedicated modules detect and fix errors |
| **Action selection** | LLM generates free-form commands | Constrained action libraries, CNN classifiers |
| **Cost efficiency** | High token usage for reasoning chains | External planning reduces tokens by 50%+ |
| **Behavioral variance** | High (nondeterministic reasoning paths) | Reduced 5.2x with symbolic augmentation (G-CTR) |

---

## Key Takeaways for Elengenix

1. **External planning is not optional for long-horizon tasks.** CHECKMATE's 20%+ improvement and 50% cost reduction demonstrate this conclusively.

2. **The Planner-Executor-Perceptor (PEP) paradigm is becoming standard.** Cochise, D-CIPHER, ZERO-APT, and CHECKMATE all converge on this architecture.

3. **Symbolic verification of LLM outputs is critical.** APT-Agent's hallucination rectification and ZERO-APT's hard-constraint action filtering show that LLM outputs must be validated externally.

4. **Neurosymbolic approaches offer the best of both worlds.** G-CTR's symbolic equilibrium computation provides what neural networks cannot: provable strategic reasoning under adversarial conditions.

5. **The field is converging on a consensus architecture:** external planner + LLM executor + external state + structured feedback loops + action constraints.

6. **Model capability is rising but architectural advantages persist.** Even as models improve (Finding 11), architectural innovations consistently improve cost efficiency, reliability, and auditability.
