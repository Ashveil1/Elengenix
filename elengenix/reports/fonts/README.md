# Bundled fonts

## wqy-microhei.ttc

WenQuanYi Micro Hei — a CJK (Simplified Chinese + kana + hangul) TrueType
collection used by `elengenix/reports/pdf.py` to render CJK text in PDF
reports with a self-contained, embedded font (no network, no system fonts).

- Upstream: http://wenq.org/ (WenQuanYi Micro Hei 1.0)
- License: GPL v2 with the Font Embedding Exception (see
  http://wenq.org/mod.php3?mod=faq — embedding these glyphs in documents
  generated with this font is explicitly permitted and does not require the
  document to be GPL).
- The file is redistributed unmodified.
